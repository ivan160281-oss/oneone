# ALTGEO — сервер и кабинет клиента

Сервер принимает данные с трекеров ALTGEO и показывает клиентам их трек.

- **Главная страница** — вход по логину и паролю. Учётные записи клиентов создаёт администратор, самостоятельной регистрации нет.
- **Кабинет клиента** (`/cabinet`): свои устройства, онлайн-карта (последние 2 часа, обновление каждые 20 секунд), отчёты за период (пройденное расстояние, время в движении, максимальная скорость, стоянки, выгрузка GPX), смена пароля.
- **Администратор** (`/admin`): создание клиентов с выдачей пароля, сброс пароля, блокировка, список всех источников данных и их трек.

Клиент видит только итоговый трек ALTGEO: время и координаты. WiFi-сети, BLE-устройства, уровни сигнала, статус GPS и сырые логи клиенту не отдаются ни на одной странице и ни в одном ответе API.

## Как строится трек

- Точки с GPS-фиксом используются как есть.
- Где GPS пропал, позиция оценивается по WiFi-сетям и BLE-маякам, которые трекер слышал в этот момент. Положение каждой сети сервер выучивает по всем точкам с GPS от всех устройств (взвешенно по силе сигнала). Сети, замеченные на слишком большой площади (например, мобильные точки доступа), не используются.
- Скачки быстрее 250 км/ч отбрасываются.

## Какие трекеры поддерживаются

Протокол взят из прошивок без изменений, перепрошивать ничего не нужно.

| Трекер | Как приходят данные | Как привязать к клиенту |
|---|---|---|
| GSM-трекер, `WIFI_GPS_T-CALL` | `POST /api/device/points`, заголовки `X-Device-IMEI` и `X-Sync-Password` (общий `WIFIGPS_PASSWORD`) | Клиент добавляет устройство по IMEI. IMEI видно в настройках Bluetooth телефона: трекер называется `ALTGEO_IMEI_<15 цифр>` |
| Трекер с SD-картой, `wifigps` | `POST /api/sync/check` и `POST /api/upload` (поле `logfiles`), заголовок `X-Sync-Password` | Клиент добавляет «Трекер с SD-картой» и получает личный пароль синхронизации. Его нужно вписать в `sync_password=` в `/WIFIGPS/sync_config.txt` |

Трекер с SD-картой собственного идентификатора не передаёт, поэтому устройство определяется по паролю синхронизации. Файлы, загруженные с общим паролем `WIFIGPS_PASSWORD`, попадают в источник `shared`, который видит только администратор.

Время в данных трекеров считается UTC.

## Запуск

Переменные окружения:

| Переменная | Назначение |
|---|---|
| `ADMIN_LOGIN`, `ADMIN_PASSWORD` | Учётная запись администратора, создаётся при первом запуске, если администратора ещё нет |
| `WIFIGPS_PASSWORD` | Общий пароль трекеров (тот, что прошит в GSM-трекер как `ALTGEO_SYNC_PASSWORD`) |
| `ALTGEO_DB` | Путь к файлу базы SQLite, по умолчанию `altgeo.db` |

Docker:

```sh
docker build -t altgeo .
docker run -d --name altgeo -p 8000:8000 -v altgeo-data:/data \
  -e ADMIN_LOGIN=admin -e ADMIN_PASSWORD='сложный-пароль' \
  -e WIFIGPS_PASSWORD='пароль-трекеров' altgeo
```

Без Docker:

```sh
pip install -r requirements.txt
ADMIN_LOGIN=admin ADMIN_PASSWORD=... WIFIGPS_PASSWORD=... uvicorn app.main:app --host 0.0.0.0 --port 8000
```

Для HTTPS поставьте перед сервером обратный прокси (Caddy, nginx с certbot). Прокси должен передавать `X-Forwarded-Proto`, тогда cookie входа будет помечена Secure. GSM-трекер сейчас ходит по обычному HTTP на 80-й порт, поэтому `/api/device/points` должен оставаться доступен и по HTTP.

Карта использует тайлы OpenStreetMap, Leaflet лежит в `app/static/leaflet`.
