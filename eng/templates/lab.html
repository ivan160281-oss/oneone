Point Lab

Upload a .txt log with partially or fully missing GPS data (heavy on bad_gps rows). This is a scratch tool - nothing gets saved to the database. For every line it computes up to four position views against the current network database, so you can compare them: the file's own recorded GPS (where present), a WiFi-only reconstruction, a BLE-only reconstruction, and a combined one.
