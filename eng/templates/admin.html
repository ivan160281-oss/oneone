Daily processing

Runs a full automatic cleanup + recompute pass across ALL uploaded data: flags points with an implausible GPS timestamp (cold-start artifact) or a speed-outlier excursion (jamming/spoofing) as bad_gps, detects and excludes co-traveling WiFi/BLE devices, then permanently deletes every point currently marked bad_gps (irreversible - see the Reports removal log for what was deleted), and rebuilds the network/device aggregates and position estimates. Runs automatically after every upload, once every 24 hours, and once immediately when the server starts. Use the button below to run it on demand.

Cleanup thresholds

Speed threshold applies to the whole algorithm consistently: the suspicious-jumps hint on the Map/Cleanup pages, manual Cleanup actions, AND the automatic speed-outlier cleanup all use this one value. The WiFi/BLE track distances work the same way for each: a network/device whose averaged position isn't within that distance of ANY point on the actual GPS track is excluded entirely - almost always a sign the average itself is polluted (e.g. the same BSSID/MAC seen once on two unrelated trips far apart), not a real reference point. WiFi's default is larger than BLE's, since a legitimate fixed access point is routinely detectable from further away than a BLE beacon.
