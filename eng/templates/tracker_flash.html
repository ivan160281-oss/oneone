Прошить устройство в браузере

Работает для ESP32-совместимых трекеров (DEVTR и другие типы на этой платформе) через Web Serial API — прямо из Chrome или Edge, без установки esptool или каких-либо программ. Устройство подключается к компьютеру по USB.

Что нужно

  1. Браузер: Google Chrome или Microsoft Edge, версия 89 и новее, на компьютере (не на телефоне — на мобильных устройствах и в Safari/Firefox эта страница прошивку не поддерживает).
  2. Кабель: обычный USB-кабель для передачи данных (не только для зарядки) — подключите устройство к компьютеру напрямую.
  3. Больше ничего не нужно — никакие файлы прошивки на компьютер скачивать или выбирать не требуется, всё уже находится на сервере. Выберите тип устройства ниже и нажмите «Прошить».

1Тип устройства и прошивка

Для «merged»-бинарников (bootloader + partitions + приложение в одном файле, как в сборках DEVTR) оставьте 0x0.

2Подключение и прошивка

Подключите устройство по USB, нажмите «Подключиться» и выберите его порт во всплывающем окне браузера, затем «Прошить».
